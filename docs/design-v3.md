# 个人网站 v3 设计方案（两页 · 2.5D · 全新配色）

> 版本：v3.0（概念提案）
> 日期：2026-08-11
> 用户核心要求：
> 1. 不要 3D，2D 为主，2.5D 更好（等距/伪3D）
> 2. 一共两页：首页 + 汉堡包页
> 3. 主题颜色不限定（不再锁红黑白）
> 4. 首页要完善、有质感、内容充实、有彩蛋
> 5. 首页右下角一个小电脑：屏幕全黑，可放照片

---

## 1. 配色系统（新，打破红黑白）

蟹堡王主题色，复古现代质感：

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸底 | #faf6ef 暖米白 | 页面背景（比纯白有质感） |
| 墨 | #1a1a18 暖黑 | 文字、主元素 |
| 番茄红 | #e0452e 砖红 | 强调、按钮、电脑 |
| 芥末黄 | #f2b84b 暖黄 | 点缀、彩蛋、高亮 |
| 深海军蓝 | #24425e 深海蓝 | 深色块、页脚、汉堡肉饼 |
| 奶油白 | #fffdf8 高光 | 卡片、浮层 |

质感来源：暖米白底 + 纸张噪点纹理 + 硬边圆角混搭 + 双色投影（红/黄）。

## 3. 首页详细设计

### 3.1 导航条
- 左：mono 字标 "ZHANG SAN / CS PORTFOLIO"
- 右：一个按钮 "🍔 汉堡包秘方 →"（指向第2页）
- 细红下划线 + 双色 hover（黄底红字）

### 3.2 主视觉（hero 区）
- 超大衬线标题：名字（如 "Zhang San"），旁边一个红色印章 "CS 2026"
- 副标语一行（≤20字）
- 三个数据块（年份/项目/技能），mono 数字
- 背景：暖米白 + 噪点 + 一个大的深蓝圆弧装饰（像海洋）
- 底部：波浪纹理（SVG 手绘波浪，海洋感）

### 3.3 内容区（充实感来源）
- **技能墙**：8-10 个色块胶囊（深蓝/红/黄/白），hover 上浮
- **简介卡片**：一张白卡片，左侧照片位（可用 QQ 企鹅或用户照片），右侧简介段落 + 手写签名线
- **时间线摘要**：横向滚动条（教育/实习/项目关键节点），红点时间轴
- **彩蛋区**：一行小字 "🦀 找到彩蛋了吗？点击右下角电脑" → 点击电脑屏幕弹出小彩蛋（如企鹅跳出来、或显示隐藏信息）

### 3.4 右下角小电脑（重点）
- 复古迷你电脑/收银机造型（深蓝或墨黑外壳，红黄点缀）
- **屏幕全黑**，屏幕内放照片（用户照片或 QQ 企鹅，初始低亮度，hover 亮起）
- 屏幕下方：红黄绿三个小指示灯
- 旁边一个小牌子 "EMPLOYEE #042"
- 点击电脑 → 全屏展示照片 + 彩蛋动画

### 3.5 彩蛋清单
1. 点击名字 → 名字短暂变成红色印章效果
2. 电脑屏幕 hover → 屏幕亮起显示照片
3. 点击电脑 → 全屏照片 + 企鹅从角落弹出
4. 波浪线底部 → 鼠标经过有波纹反应
5. 键盘按 "K" → 汉堡包页面直接跳转（快捷键彩蛋）

## 4. 汉堡包页详细设计（2.5D）

### 4.1 2.5D 汉堡（不用 Three.js）
用 CSS 等距视角（isometric）实现：
- 整个汉堡容器 `transform: rotateX(55deg) rotateZ(45deg)` 形成等距俯视
- 6 层用扁圆柱/圆角矩形堆叠，每层有底部阴影（伪立体）
- 或：侧视图分层 + 顶部椭圆投影，形成 2.5D 剖面感
- hover 层放大：该层 transform: scale(1.1) translateY(-4px) + 阴影加深

### 4.2 秘方卷轴（左侧）
- 折叠态：一个 2.5D 卷轴（两端圆棍 + 纸卷）
- 点击展开：纸卷水平展开（width 动画），显示 6 层秘方列表
- 每层：色点 + 编号 + 名称 + 对应栏目
- hover 条目 → 汉堡对应层高亮放大（组件联动）

### 4.3 详情面板
- 点击秘方条目 → 右侧滑出面板
- 面板内容：该栏目的详细信息（简历/项目/GitHub/兴趣/联系/关于）

## 5. 技术栈

- Vue 3 + Vite（保留）
- **移除 Three.js**（不用 3D 了）
- 2.5D 效果：纯 CSS transform（isometric）+ 分层阴影
- 纹理：SVG feTurbulence 噪点 / 纸张质感
- 波浪/装饰：SVG 手绘
- 页面切换：两页用路由（vue-router）或单页状态切换（简单用状态切换）

## 6. 需要用户提供

1. **真实姓名/个人信息**（现在用占位符）
2. **电脑屏幕里的照片**（QQ 企鹅 or 个人照片）
3. 项目经历/技能/时间线内容
